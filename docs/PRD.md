# Todo List PRD

## 1. 项目目标

实现一个简单的纯前端 Todo List Web 应用，
帮助用户记录和管理日常任务。

## 2. MVP 范围

### 2.1 新增任务

用户可以输入任务名称并创建任务。

要求：

- 任务名称不能为空
- 创建后立即显示在任务列表
- 创建后自动保存

### 2.2 查看任务

页面展示所有任务。

每个任务显示：

- 任务名称
- 完成状态
- 编辑按钮
- 删除按钮

### 2.3 编辑任务

用户可以修改已有任务名称。

要求：

- 修改内容不能为空
- 保存后立即更新
- 自动保存

### 2.4 删除任务

用户可以删除指定任务。

### 2.5 完成任务

用户可以切换任务：

- 未完成
- 已完成

## 3. 数据持久化

刷新页面后任务仍然存在。

第一版仅保存于当前浏览器。

## 4. 非 MVP

第一版不实现：

- 用户登录
- 云同步
- 后端
- 数据库
- 截止时间
- 优先级
- 标签
- 提醒
