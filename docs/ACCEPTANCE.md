# MVP 手动验收清单

在项目目录运行 `npm run dev -- --host 0.0.0.0`，用浏览器打开终端显示的地址。

## 基础流程

- 新增一项任务，确认其立刻出现；刷新页面后仍存在。
- 提交空白任务，确认页面提示“任务名称不能为空。”且没有新增任务。
- 勾选和取消勾选任务，确认完成状态与删除线正确变化；刷新后状态仍存在。
- 编辑任务并保存，确认标题更新；再次编辑后选择取消，确认标题不变。
- 删除最后一项任务，确认“还没有任务”提示重新出现。
- 分别选择“全部”“未完成”“已完成”，确认列表仅显示对应任务，且未完成数量始终正确。
- 点击“清除已完成”，确认已完成任务被移除、未完成任务保留；刷新页面后清除结果仍然存在。

## 页面检查

- 在桌面浏览器确认输入框、按钮、任务操作不重叠，键盘 Tab 聚焦时可见焦点样式。
- 在手机或浏览器窄屏模式确认添加区域纵向排列，编辑输入框与操作按钮清晰可点击。
